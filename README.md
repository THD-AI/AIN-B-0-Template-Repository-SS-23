# THD AI – student project starter

A lightweight starting point for a student project or a collection of your own learning notes. The historical repository URL is retained; the template is no longer tied to a semester.

## Use this template

1. Choose **Use this template** on GitHub and create a repository in THD AI (members) or in your own account.
2. Replace this README with your project's name, purpose, status, maintainers, setup steps, and one small contribution someone can try.
3. Choose the licence appropriate to work you own. The inherited licence here is for the original notes template; it is not a universal software licence.
4. Invite collaborators, use branches and pull requests, and share your idea in [Discussions](https://github.com/orgs/THD-AI/discussions/categories/ideas).

The optional `Lecture-Notes/Week-00-Template.md` is a starting structure, not a requirement. Use the folder structure that fits your project.

Share original explanations and code. Link to third-party teaching material rather than copying textbooks, slides, exams, or restricted content. See [THD AI's contribution guide](https://github.com/THD-AI/.github/blob/main/CONTRIBUTING.md).
